1. 交换机接口 Down 排查手册
1. 故障现象
现象一：接口指示灯常灭，业务流量中断，无法正常收发报文。

现象二：执行 display interface 命令，回显中 current state 字段显示 DOWN。对于三层物理接口，即使物理状态为 UP，若未配置 IP 地址，协议状态 Line protocol current state 仍为 DOWN。

现象三：display logbuffer | include DOWN 可查看到类似日志：The interface status changes. (ifName=10GE1/0/1, AdminStatus=UP, OperStatus=DOWN, Reason=Interface physical link is down)。

2. 可能原因
原因一：接口被管理性关闭（shutdown），display interface brief 中端口状态显示 ADM，需执行 undo shutdown 激活。

原因二：物理链路故障，包括本端或对端设备的光模块、光纤、网线、单板或接口硬件故障。

原因三：两端配置不一致，如端口协商模式、速率、双工模式不匹配，导致物理链路无法正常建立。

3. 排查步骤
检查接口管理状态
执行：display interface brief
关注：端口名称与物理状态字段
异常判断：若显示 ADM 则说明被管理性关闭；若显示 PHY 则为物理 DOWN，需继续排查硬件。

检查接口详细状态与错误计数
执行：display interface GigabitEthernet 0/0/1
关注：current state、Line protocol current state、CRC 错误包数、丢包数
异常判断：CRC 错误持续增长说明链路质量有问题或接口硬件故障。

检查接口日志
执行：display logbuffer | include DOWN
关注：链路 DOWN 的时间和原因字段
异常判断：Reason=Interface physical link is down 说明物理链路中断。

检查两端协商配置
执行：display current-configuration interface GigabitEthernet 0/0/1
关注：协商模式、速率、双工配置
异常判断：两端配置不一致需调整为相同模式。

4. 处理方案
如果是原因一：进入接口视图执行 undo shutdown 激活端口，并确认该接口不应被管理性关闭。

如果是原因二：更换光模块、光纤或网线，检查本端和对端设备硬件状态。可先尝试更换网线排除线缆问题。

如果是原因三：统一两端设备的协商模式、速率和双工配置，建议使用自协商模式或强制设置相同的速率/双工。

5. 注意事项
对生产环境接口执行 shutdown/undo shutdown 操作前，需确认接口无业务流量或已安排维护窗口。更换光模块时注意静电防护，光模块拔出后需及时安装防尘帽。接口 Down 可能影响上层路由协议邻居关系，操作后需验证 OSPF/BGP 邻居是否恢复。
